# Surtilandia Ecommerce Demo

Demo funcional de tienda y panel administrativo construida con Flask + SQLite.

## Qué incluye

- Tienda pública con catálogo
- Carrito en navegador
- Checkout como invitado
- Seguimiento por ID
- Panel administrativo con login
- Gestión de productos
- Gestión de pedidos
- Base de clientes
- Reportes básicos de ventas
